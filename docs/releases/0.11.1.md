# 0.11.1 — Safer MCP recovery and smaller chat history

- Fix desktop MCP requests failing before they are sent: safely fall back or resume without repeating requests that may already have run remote tools. (#60)
- Save the durable MCP checkpoint once per turn instead of rewriting large chats after every step. (#60)
- Keep a rolling readable summary before releasing older API history after repeated encrypted compactions, preserving context when changing providers, models or accounts. (#61)
- Improve voice startup diagnostics and redact echoed connection credentials.

The voice-session 404 reported in #62 remains under investigation. This release does not claim to fix that account-specific failure.

Validation: 922 automated tests; TypeScript, Svelte and production build checks; native Obsidian checkpoint checks; a live ChatGPT summary and voice connection. Failed summaries preserve the original history, and visible conversation text remains retained.
