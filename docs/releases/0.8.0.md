# 0.8.0

Add remote MCP servers for Anthropic and OpenAI API-key chats. The provider connects to enabled servers and calls their tools; the chat shows the tool name, server, result and failures. ChatGPT account chats do not use these servers.

Servers start disabled. Configure a public HTTPS address and an optional token, then enable servers you trust. Enabled MCP tools run without per-call approval and can receive conversation context. Tokens remain in this device’s Obsidian SecretStorage, outside synced settings.

Disabling/removing a server or changing its endpoint or authorization invalidates its native tool replay and OpenAI response cursor. Clearing a token stays cleared after restart. Remote results share bounded tool history; non-text remote payloads are omitted from replay with a note. Truncated answers retain completed MCP receipts, and failed Responses with remote calls are not automatically retried.

Stop cannot recall an already-sent remote request. Vault Undo does not reverse external MCP changes. Streaming, background chats, long-chat storage migration and voice are reserved for later releases. Minimum Obsidian version remains 1.11.4.

Validation: 527 automated tests, TypeScript, Svelte checks, clean production rebuild, native desktop and physical iPhone settings QA, plus real ChatGPT subscription conversation/reload continuation. Live Anthropic/OpenAI API-key MCP calls were not exercised; provider requests and remote receipts were verified with mocked transport. See [QA evidence](../phase4-qa.json).
