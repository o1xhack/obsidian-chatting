# 0.10.0

Long conversations now show context usage and token totals in the header, with estimated costs when API pricing is available. Configure the compaction point or choose Compact now to summarize earlier context. The conversation stays readable; the model continues from the summary. Subscription accounts show usage without an API cost estimate.

Chats now save to individual files with a compact index. The upgrade preserves a backup of the old chat-state file before migrating it. The full visible conversation is retained, with earlier turns loaded as you scroll up. Settings show the saved chats' total size, and large chats show their size in the list.

The integration also protects interrupted migrations and deletions, future-version chat files, manual compaction cancellation, stale chat navigation, and remote MCP operations during compaction or storage failures. MCP receipts and the existing permission/retry protections remain intact.

Includes PR #44–45. Voice #46 remains for a later release. Minimum Obsidian version remains 1.11.4. See [QA evidence](../phase6-qa.json) and [review notes](../phase6-review.md) for validation and limitations.
