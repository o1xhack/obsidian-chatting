# 0.9.0

Answers now appear as the model writes them. Stop keeps the text already shown. Desktop uses streamed HTTPS; mobile streams where the provider permits browser requests and otherwise receives the buffered answer.

Keep typing while an answer runs: added text joins the next step or runs as the next turn. Switch chats or start another while sent answers continue in their own conversation. Background questions wait for you to return to that chat.

On mobile, transient requests interrupted by backgrounding can resume with a bounded retry allowance. After an app restart, Continue finishes a pending turn from saved history without rerunning completed tools. Original selection restrictions remain enforced. MCP operations that may already have run are not automatically repeated, and available remote receipts survive stream failures. After restart, an interrupted MCP-capable request with unknown external effects shows a warning instead of Continue.

Chat history remains version 3. Long-chat compaction/storage migration and voice are reserved for later releases. Minimum Obsidian version remains 1.11.4.

Validation and limitations: see [QA evidence](../phase5-qa.json) and [review notes](../phase5-review.md). Live API-key provider calls and physical mobile background suspension are not covered by this release's local environment.
